# Jogo da Cobrinha

Um jogo da cobrinha desenvolvido com React, como projeto prático de estudo e aplicação dos conceitos de desenvolvimento frontend.

## Funcionalidades

- Movimentação por teclado e botões na tela.
- Geração aleatória de comida.
- Sistema de pontuação.
- Aumento progressivo da velocidade.
- Detecção de colisão com o próprio corpo.
- Reinício da partida.
- Layout responsivo para diferentes tamanhos de tela.

## Tecnologias utilizadas

- React
- JavaScript
- CSS
- Vite

## Como executar o projeto

1. Clone este repositório.
2. Abra a pasta do projeto no terminal.
3. Instale as dependências:

   `npm install`

4. Inicie o servidor de desenvolvimento:

   `npm run dev`

## Objetivo do projeto

Praticar lógica de programação, gerenciamento de estado com React, eventos, efeitos, movimentação de elementos e construção de interfaces responsivas.
